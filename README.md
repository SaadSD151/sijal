# سِجال — حرب المدن

لعبة حرب استراتيجية على المتصفح: وسّع أرضك، خذ المدن، تحالف، والعب أونلاين مع أخوياك.

- الموقع: https://sijal-sa.netlify.app/
- الكود في `src/`، والبناء بأمر `node build.js` اللي يطلّع الملفات الجاهزة في `dist/`.
- Netlify ينشر مجلد `dist/site` تلقائياً مع كل تحديث على الفرع `main`.
